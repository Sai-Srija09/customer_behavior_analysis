Customer Shopping Behavior Analysis
End to end data analytics project using Python, SQL, and Power BI

1.Overview
This project analyzes customer shopping behavior using transactional data from 3,900 purchases. The goal is to uncover insights into spending patterns, customer segments, product preferences, and subscription behavior to support data‑driven business decisions.

2.Dataset
Rows: 3,900
Columns: 18
Features: Customer demographics, purchase details, shopping behavior, review ratings, and shipping type.
Missing Data: 37 values in review ratings handled via imputation.

3.Tools & Technologies
•	Python – Data loading, cleaning, EDA
•	PostgreSQL – SQL queries for structured business analysis
•	Power BI – Interactive dashboard visualization
•	Gamma – Report and presentation creation

4.Project Steps
•	Data Loading & Cleaning – Imported dataset, handled missing values, standardized columns.
•	Exploratory Data Analysis (EDA) – Summary statistics, feature engineering (age groups, purchase frequency).
•	Database Integration – Loaded cleaned dataset into PostgreSQL.
•	SQL Analysis – Queries on revenue, segmentation, product ratings, shipping types, and subscription behavior.
•	Dashboard – Built Power BI dashboard to visualize customer demographics, revenue by category, and age group trends.
•	Reporting – Created structured report and presentation using Gamma.

5.Dashboard
The Power BI dashboard highlights:
•	Customer demographics and subscription status
•	Revenue and sales by category
•	Age group contributions
•	Shipping type comparisons

 6.Results & Insights
•	Male customers generated nearly twice the revenue of female customers.
•	Non‑subscribers contributed higher overall revenue, but subscribers showed consistent spending.
•	Clothing was the most purchased category; accessories like jewelry and sunglasses ranked high.
•	Loyal customers formed the largest segment, emphasizing retention strategies.

 7.How to Run
•	Clone the repository.
•	Run Python scripts for data cleaning and EDA.
•	Connect PostgreSQL and execute SQL queries.
•	Open Power BI file to explore the dashboard.
•	Review the Gamma presentation for summarized insights.
